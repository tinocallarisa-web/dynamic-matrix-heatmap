An interactive pivot table with a heatmap. The people reading your report pick the rows, the columns, the value and how it is shown — from dropdowns inside the visual, without edit rights. Supported Power BI features: cross-filtering by cell (and by group), Ctrl+click multi-select, highlighting · bookmarks · tooltips · context menu · custom color rules · format on the canvas (on-object) · keyboard navigation · high contrast · number formats from the model · 12 panel languages · data loaded in segments past 30,000 rows. Pivot: Show as absolute or % in the visual, row groups with subtotals that open and close, Others so totals always add up, sorting by name, total or any column, days and months in calendar order, order by similarity, exact averages and distinct counts with Detail (rows), 12 color schemes and 5 style templates.

Quick Start

1. Add the visual to your report

In Power BI Desktop, go to the Visualizations pane → click the three dots → Get more visuals → search for Dynamic Matrix Heatmap.

2. Give it the fields to pivot

Drag two or more fields into Dimensions — region, product, month, channel… — and at least one value into Measures.

3. Pick rows and columns in the visual

Choose the X axis, the Y axis and the Value in the bar at the top. Anyone reading the report can change them, and the matrix follows.

4. Optional: exact averages

Put an ID that identifies each row — the order, the ticket, the customer — in Detail (rows). Averages and distinct counts are then exact for any X/Y pair.

The controls in the visual

By default the controls sit in a panel on the left, each with its label above and its value in full. The ⚙ button folds the panel to a thin strip so the pivot gets the whole width; on narrow visuals it starts folded. In Format → Layout → Controls the author can move them to a top bar instead, or hide them in reading view to publish a fixed view.

Exact numbers

Because rows and columns are chosen inside the visual, Power BI cannot aggregate to the pair you see: it sends the values at the grain of every dimension you bound, and the visual combines the rest.

  • Sum, Min, Max and Count combine exactly. Always.
  • Average needs Detail (rows) to be exact. Without it the visual combines averages, and a note says so while you edit.
  • Count (Distinct) — set it in the field well as usual. If that column is also in Dimensions or Detail (rows), the visual counts it exactly for any X/Y pair. If not, a note says the number may not be exact and how to fix it.
  • Ratios and DAX measures that are not additive are flagged the same way: bind only the dimensions you compare, or use an additive measure.

Format on the canvas

In format mode, click the cell values, the row or column headers or the dropdown bar to change font, size and color without opening the Format pane.

Sorting, Others and similarity

  • Click a column header to sort the rows by that column: highest first, then lowest first, then back to the chosen order. The arrow shows the direction; the order is saved with the report.
  • Automatic keeps the order of the data, and puts days of the week and months in calendar order (English, Spanish, Portuguese, French, German, Italian; full or short names).
  • Others: beyond Maximum rows or columns, the categories with the smallest totals are grouped in one Others (N) row or column, so totals still add up. A note says how many were grouped. Turn it off to leave them out — the note then says they are out of the totals too. Others is drawn last and does not stretch the color scale.
  • Order by similarity Pro puts rows (or columns) with the same pattern next to each other — weekday-heavy regions together, weekend-heavy ones together.

Selection & filtering

  • Click a cell to filter the rest of the page to that intersection; click it again to clear; Ctrl+click to add cells.
  • With Group rows, a cell filters by its column, its row and its group — Bikes in North, not Bikes everywhere.
  • A cell in Others filters by every category it groups.
  • Bookmarks keep the selected cells and restore them.
  • Selections in other visuals highlight the cells they touch and dim the rest.
  • Right-click a cell for the Power BI context menu (Include, Exclude, Drill through).

Accessibility

  • Keyboard: Tab through the dropdowns, headers and cells; Enter or Space selects a cell (Ctrl to add), sorts by a column header or opens and closes a group.
  • Screen readers: column headers announce their sort order; groups announce whether they are open.
  • High contrast: with a Windows high-contrast theme the color scale gives way to the system colors, and selected cells get a system-colored outline.
  • Two colour-blind safe schemes: Viridis and Cividis.

FAQ

How is this different from the Power BI matrix?

In the native matrix the author fixes the rows and columns. Here the reader chooses them — and the value, and how it is shown — from the visual itself, without edit rights. It works like a pivot table with a heatmap.

Do I need DAX?

No. Drag fields, choose the aggregation in the field well, and switch between absolute and percentages with Show as in the visual.

Can I show the same measure as a value and as a percentage?

Add it once and use Show as (Pro). Each measure remembers its own choice. Adding the same field twice does not help: Power BI treats both copies as one, so renaming one renames the other.

When do I need Detail (rows)?

When you show averages, or want distinct counts that are exact for any pair. Sums, minimums, maximums and counts are exact without it.

How do I count distinct customers?

Add the customer column to Measures and choose Count (Distinct) in its menu, and add the same column to Dimensions or Detail (rows). The visual then counts unique customers per cell, exactly. With Pro, a Detail field is also offered directly in Value.

Why do percentages of a row not add up to 100 with distinct counts?

A customer who appears in several columns is counted once in each. That is how distinct counting works, not a defect.

What is Others?

When an axis has more categories than the maximum, the smallest are grouped in one Others row or column so the totals stay true. Clicking an Others cell filters by all of them.

Can the reader sort?

Yes: clicking a column header sorts the rows by it. The author sets the default order in Rows and columns.

What does Order by similarity do?

It reorders rows (or columns) so that those with the same shape sit together — a hierarchical clustering of their profiles. Patterns hidden in alphabetical order become blocks you can see.

Do bookmarks work?

Yes. A bookmark keeps the selected cells and restores them. The X, Y, value, group and sort are saved with the report.

Where did Weights for averages and Distinct count of go?

Version 1.2 replaces both with Detail (rows): one optional ID makes averages and distinct counts exact. Fields that were in Distinct count of stay where they are — it is the same well with its new name. A field in Weights for averages is no longer used; add an ID to Detail (rows) instead.

Which languages is the visual in?

English, Spanish, French, German, Italian, Portuguese (Brazil and Portugal), Dutch, Polish, Japanese, Simplified Chinese and Korean — the Format pane and the bar in the visual. It follows the language of Power BI.

Does my data leave Power BI?

No. The visual has no network permission; everything is computed inside the report. See Privacy.
