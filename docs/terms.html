6. Accuracy of aggregation

The visual re-aggregates values when projecting a multi-dimension result onto the two dimensions you select. Sum, Minimum, Maximum and Count re-aggregate exactly. Average is an unweighted approximation. A distinct count produced by a DAX measure cannot be re-aggregated correctly by any client — use the Distinct count of field well, where the visual counts unique values from the raw column and the result is exact. You are responsible for validating figures before relying on them for decisions.
