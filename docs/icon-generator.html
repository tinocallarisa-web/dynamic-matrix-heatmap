Which one goes in assets/icon.png?
Microsoft's documentation specifies 20×20, but plenty of published visuals ship larger icons and pass certification. Use 300×300 for the AppSource listing. For assets/icon.png, start with 20×20 to match the documented requirement — if the packager or the review complains, swap it for the 36×36.
